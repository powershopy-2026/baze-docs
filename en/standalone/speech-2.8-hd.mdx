Call `POST /v1/audio/speech` through the baze platform unified API to synthesize speech with `speech-2.8-hd`.

This is the standalone entry page for `speech-2.8-hd`. It describes the same public platform API as the page under the Model APIs menu and documents only the fields and response behavior currently exposed by the platform API. It does not represent the complete MiniMax upstream capability set.

## Authentication

Provide your API token in the request headers:

```http
Authorization: Bearer <token>
Content-Type: application/json
```

## Non-streaming request

```bash
curl --request POST \
  --url https://baze-api.powerbuyin.top/v1/audio/speech \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "speech-2.8-hd",
    "input": "Summarize today’s system status in a natural tone.",
    "voice": "English_Graceful_Lady",
    "response_format": "mp3",
    "metadata": {
      "output_format": "url"
    }
  }'
```

On success, the platform API returns `302 Found`. The `Location` response header contains the temporary audio URL.

## Streaming request

Set `stream_format` to any non-empty value to enable streaming output:

```bash
curl --request POST \
  --url https://baze-api.powerbuyin.top/v1/audio/speech \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "speech-2.8-hd",
    "input": "Read this sentence in a calm voice.",
    "voice": "English_Graceful_Lady",
    "speed": 1,
    "response_format": "wav",
    "stream_format": "pcm"
  }'
```

On success, the platform API returns `200 OK` with the `text/event-stream` content type.

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | Yes | Must be `speech-2.8-hd`. |
| `input` | string | Yes | Text to synthesize, up to `10000` characters. Use streaming output for text longer than `3000` characters. |
| `voice` | string | Yes | A voice name supported by the platform API. |
| `speed` | number | No | Speaking rate. |
| `response_format` | string | No | Audio encoding format, such as `mp3`, `wav`, or `pcm`. |
| `stream_format` | string | No | Any non-empty value enables streaming output. |
| `metadata.output_format` | string | No | Non-streaming requests currently support only `url`. |

## Capability boundaries

- This page lists only fields currently exposed publicly by the baze platform.
- Non-streaming requests return a temporary audio URL in the `Location` response header instead of an audio JSON payload.
- This page is a platform channel view of the MiniMax upstream capability. It does not represent the complete upstream capability set.
