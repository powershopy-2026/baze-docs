
## Kling 4.0 文档：说明暂不对接主体和音色
- 修改 12 个 Kling 4.0 OpenAPI 文件（视频 4 个 + 图片 2 个，中英各一份）：
  - 视频提交接口（text2video / image2video / omni-video）的 info + operation description 统一追加"平台暂时不对接主体（element）和音色（voice）"
  - omni-video 字段级：type 枚举、element_id、voice_id、contents、settings.audio 说明均标注暂不对接；描述中移除"主体、音色"作为已支持素材的表述
  - image-generations：type 枚举、element_id、contents 标注主体暂不对接
  - 两个 tasks 查询接口：description + TaskOutput.type 标注主体/音色类型暂不返回
- MDX 页面均为 openapi 引用桩，无需改动
- 环境注意：本仓库文件带 %TSD-Header-###% 透明加密头，python/node 等外部进程读盘是密文，校验需走 Read 工具
