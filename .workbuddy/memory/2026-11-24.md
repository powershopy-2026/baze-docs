# 2026-11-24

## Kling 4.0 图像生成文档：移除组图（series）能力
- 文件：`api-reference/zh-Hans/zmodelImage/kling/kling-4.0-image-generations.json` 与 `api-reference/en/zmodelImage/kling/kling-4.0-image-generations.json`
- 改动：
  - `Kling4Settings.result_type` 枚举仅保留 `single`，删除 `series` 枚举值
  - 删除 `series_amount` 字段（含 oneOf 定义与 x-valid-when）
  - `n` 描述移除 series 相关注释及 `x-valid-when`
  - 示例 `image_to_series`（图生组图）改为 `image_to_image`（图生单图），settings 改为 `result_type: single`
  - info/post description 移除「文生组图/图生组图」措辞；resolution、aspect_ratio 描述移除「单图与组图均适用」
- 注意：这两个 JSON 带有 `%TSD-Header-###%` 透明加密头，Python 直接读为密文，但 Read/Grep/文档工具链可透明读取，属正常现象，JSON 校验需用 Read/Grep 间接确认。
- 其他含 `series_amount` 的文件（kling-v3-omni-image-omni.json、kling-image-o1-image-omni.json、omni-image-status.json，中英文）未改动，仅针对 Kling 4.0。
