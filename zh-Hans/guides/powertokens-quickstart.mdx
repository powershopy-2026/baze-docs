PowerTokens 为生成式 AI 应用提供统一接口。你可以通过同一个平台接入聊天、图像、视频和音频模型，并在控制台管理 Credits、API Key、调用日志和用量统计。

这篇指南帮助你完成第一次接入。建议按顺序完成下面三个任务。

## 1. 注册账号，并根据活动及账户情况获得 Credits

访问 [PowerTokens 官网](https://www.powertokens.ai/) 并创建账号。

你可以使用：

- Google 登录
- GitHub 登录
- 邮箱注册

注册完成后，进入 **Dashboard** 控制台。

注册完成后，请先查看平台当前是否有新用户注册赠送积分活动，并确认账户是否因符合活动条件而获得赠送积分。该活动并非长期持续，未开展活动时，新用户注册不会自动获得赠送积分。若账户已有可用积分，可直接进入下一步创建 API Key，无需先充值；如果当前没有活动、账户未获得赠送积分，或现有积分不足，再打开 [**Billing**](https://www.powertokens.ai/zh-Hans/billing) 页面，按实际需要选择适合的购买套餐。

![PowerTokens Billing 页面](/images/guides/powertokens-quickstart/billing.png)

Credits 是你的账户余额。调用模型时，平台会根据模型用量从 Credits 中扣费。

当前支付方式包括：

- 信用卡
- PayPal

提示：充值是否为开始使用平台的必要步骤，取决于账户是否已有可用 Credits。新用户注册赠送积分仅在平台当前开展相关活动且用户符合活动条件时适用；平台未开展活动时，注册不会自动获得赠送积分。若账户已获得赠送积分，可直接创建 Key 并试用；否则应根据实际使用需求充值。

## 2. 创建 API Key 并调用模型

充值完成后，创建 API Key，并通过平台 API 或 **Playground** 发起第一次请求。

你会完成：

- 创建并保存 API Key
- 设置 Key 的额度、重置周期和过期时间
- 在 **Models** 中选择模型
- 使用 `https://baze-api.powerbuyin.top` 调用平台接口
- 在 **Playground** 中调试 Prompt 和参数

继续阅读：[创建 API Key 并调用模型](/zh-Hans/guides/api-key-and-model-call)。

## 3. 查看日志和用量统计

发起请求后，使用 **Logs** 和 **Dashboard** 追踪调用结果、排查错误并控制成本。

你可以查看：

- 请求记录
- 生成结果
- 错误信息
- Credits 消耗
- 请求次数和成功率
- API Key 维度的用量

继续阅读：[查看日志和用量统计](/zh-Hans/guides/logs-and-usage)。
